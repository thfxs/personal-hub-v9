安全提示：远程同步现在要求 受信任的 HTTPS 连接 + 电脑端 AES-GCM 加密保险库，缺少任一项将拒绝提交。自签名证书必须先由你验证并正确配置客户端信任；不要忽略证书警告。手机浏览器、GitHub Pages 和 APK 依然是独立数据来源，首次迁移须由你确认备份后导入。

APK 安全电脑连接 · 首次手动核对

从电脑本机运行 python tools/show_bridge_fingerprint.py，核对安全证书的 SHA-256 指纹与当前电脑 IPv4（必须包含在证书 SAN 中）。指纹不能从尚未验证的手机连接自动获取。更换证书、电脑 IP 时重新核对；不要上传私钥。

03 · 确认同步

提交时先保存本地保护快照，再将合并结果写入电脑（版本不匹配会拒绝），最后写入本机并核对。完成后需重新进入主控以刷新界面。电脑端保留最近 8 个旧版本；不自动同步事件已读状态及电脑桥设置。
