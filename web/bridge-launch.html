PERSONAL HUB / LAN CONNECTOR / 1.7

电脑快捷指令

手机与电脑连同一个可信 Wi-Fi 后，输入桥接器显示的电脑局域网 IPv4 地址。仅跳转到电脑上的页面；不会把数据上传到 GitHub，也不会在这里保存配对码。

APK 原生连接

使用荣耀 V9 安装的 Personal Hub APK 时，优先打开应用内的证书绑定和快捷指令页：不会把内部数据源切换成电脑网页。

打开 APK 内快捷指令页 · 绑定电脑证书/安全同步

网页模式连接电脑

第一次打开后，在电脑终端读取 8 位配对码并完成配对。电脑没有授权时，指令只会进入待发队列。

连接说明

电脑需要先运行 bridge/server.py。这里只做用户主动点击后的顶层页面跳转，不从 GitHub Pages 读取电脑的私有数据。默认使用 HTTPS，电脑需先准备受信任的证书。

远程配对与数据同步只允许受信任的 HTTPS 连接；未受信任或过期的证书请先处理，不要忽略安全警告。Windows、Mac、Ubuntu 均需在电脑端启动安全桥接器，且不应开放公网端口。
